# Urban Manager
**2024-2025**

**Теги:** UI/UX, EdTech, WEB

![Обложка проекта Urban Manager](./images/urban-main.png)

## О проекте
Urban University — онлайн-университет, где обучают IT-профессиям.

Моя задача — развивать и поддерживать кабинет менеджера по продажам. Кабинет менеджера/руководителя представляет собой несколько разделов с календарями, таблицами и дашбордами. Задача менеджера — продажа обучающих курсов. Клиенты (студенты) могут оплатить весь курс сразу или оформить кредит (рассрочку) на обучение.

### Разделы:
* **Рабочий календарь менеджера** — это инструмент для управления рабочим временем и лидами. В календаре видны все дела и взаимодействия для выбранного менеджера или подразделения. Например, можно перенести пробный урок, сформировать ссылку на оплату, назначить видео-встречу, посмотреть историю. Также в календаре можно увидеть свободные и занятые слоты, а также суммарную информацию об уроках, продажах, конверсии. Руководитель отдела продаж в свою очередь может видеть данные по всем сотрудникам.
* **Дашборд** помогает руководителям подразделений управлять продажами, собирая данные об обороте, продажах, прибыли по каждому менеджеру. Представляет собой саммари по каждому каналу оплаты и сводные таблицы с продажами по каждому менеджеру. C помощью этих таблиц можно сопоставить данные по продажам (продажа, отказ, одобрение), чтобы принять решение об эффективности работы сотрудников.
* **Инфопанель** — это инструмент для просмотра и анализа конверсии по одобренным сделкам (покупка обучения в рассрочку). Тут можно посмотреть саммари по всем видам (банкам) оплаты и данные о продажах каждого менеджера.
* **В Таблице продаж** данные струтурированы в зависимости от типа оплаты: оплата, доплата, аванс.
* **Аналитика** — это виртуальная панель инструментов, которая демонстрирует аналитические данные об одобренных и отклонённых кредитах на обучение. Такой дашборд даёт возможность быстро оценить текущее состояние и долю одобренных кредитов, идентифицировать проблемы и выявить возможности для роста.
* **Таблица по заработной плате** — это инструмент, который позволяет HR-специалистам отслеживать основные метрики, связанные с трудовыми ресурсами, в том числе сумму зарплат работникам в разрезе исходя из количества консультаций, суммы продаж, % одобрения по кредитам.
* **Дашборд для анализа гипотез** — это интерактивная аналитическая панель, которая помогает быстро тестировать гипотезы. Например, что будет если изменить метоположение кнопки, добавить новый способ оплаты, упростить регистрацию и т.п. Благодаря тому, что данные в метриках обновляются автоматически, можно запускать новые кампании, менять креативы, текст или стратегии размещения и сразу оценивать их эффективность.

## Что делала

### — Дизайн-поддержка проекта
В уже существующие сценарии были добавлены микро-функции. Так, например, в Рабочий календарь были добавлены действия «Перенести лид», «Отметить лид как недозвон» и т.п. Это существенно расширило возможности работы с лидами.

А в календарь сотрудника, который распределяет лиды, был добавлен раздел с уведомлениями. Благодаря этому стало возможно быстро получать информацию о действиях и актуальных статусах.

### — Разработка нового функционала
Был разработан новый раздел — Инфопанель — это инструмент для просмотра и анализа конверсии по одобренным сделкам (покупка обучения в рассрочку). Тут можно посмотреть саммари по всем видам (банкам) оплаты и данные о продажах каждого менеджера.

### — Оптимизация макетов и ui-kit
Я начала работу с уже готовыми макетами сервиса, в которых не было чёткой структуры используемых компонентов, многие вещи не были автоматизированы. Я привела в порядок макеты, по максимуму автоматизировала ui-kit.

### — Адаптация под другие бренды компании
У компании есть несколько брендов с аналогичным набором продуктов, поэтому дизайн кабинета менеджера также был адаптирован под другие продукты.

## В итоге
Спроектирован полноценный инструмент для управления продажами, который позволяет:
— управлять рабочим временем, продажами и планировать действия;
— представить набор данных максимально наглядным и понятным;
— держать под контролем ключевые бизнес-показатели;
— находить взаимосвязи, выявлять негативные и положительные тенденции;
— давать оперативную сводку в режиме реального времени.
